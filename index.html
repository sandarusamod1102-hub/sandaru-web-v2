COMMON QUESTIONS

How long does the code last?

About two minutes. If it expires, request a new one.

Which number format should I use?

Country code first, no plus and no spaces. Example: 947XXXXXXXX.

The code does not arrive. What now?

Check your number, wait a moment and try again. Still stuck? Message the owner from the Support page.

Can I link more than one number?

Yes, request a separate code for each number.
